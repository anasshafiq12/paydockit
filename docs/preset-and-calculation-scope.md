# Support matrix

| Mode | Enabled | Scope |
|---|---|---|
| General format | Yes, default | USD and A4 suggestions; all amounts editable |
| US, UK, Canada, Australia, India, Pakistan, Saudi Arabia, UAE | Yes, optional | ISO currency and paper suggestions, confirmation before application; no conversion or tax |
| Manual payslip | Yes | Decimal gross, deductions, net, reimbursements, cash, separate employer contributions |
| Universal calculators | Yes | Explicit user assumptions; no statutory entitlement decisions |
| Custom progressive / fixed-base rules | Yes | User-configured estimates only; dated/versioned with source notes |
| Reviewed jurisdiction-specific packs | No | No enacted rate, payroll review, or compliance claim fabricated |
| English documents | Yes | Searchable PDF, HTML preview, print; broader characters may require browser print |
| Arabic / Urdu panels | Draft print only | Self-hosted fonts and explicit translated fields. Full translated prose, native review and extraction checks pending |
| Bilingual direct PDF | No | Disabled rather than emitting unverified shaping |
| Blank templates | Yes | Print mode without filled amounts; no validation exemption on completed PDF downloads |
| PNG / SVG stamps | Yes | Fixed escaped schema; ordinary authorized business graphics only |
| CSV batch PDF ZIP | Yes | 100 rows / 5 MB input, manual English PDFs, row manifest; no combined PDF or worker execution |

Formatting does not establish legal compliance, verify identifiers, certify an employer, or guarantee visa/bank acceptance. Image signatures are not cryptographic signatures.
